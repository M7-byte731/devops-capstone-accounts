## Overview
A RESTful microservice for managing customer accounts built with Python and Flask.

## Endpoints
- `GET /accounts`
- `GET /accounts/<int:account_id>`
- `POST /accounts`
- `PUT /accounts/<int:account_id>`
- `DELETE /accounts/<int:account_id>`
